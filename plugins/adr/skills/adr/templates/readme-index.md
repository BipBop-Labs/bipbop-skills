# Architecture Decision Records

Read this index first. Open only the ADRs whose `paths` or topic match the code
you are about to touch. Never load every ADR.

Rules for agents:

- An `accepted` ADR is binding. Do not silently undo it. Propose changes for human confirmation.
  Then rewrite the affected records in place. Consolidate overlapping records and remove
  obsolete ones. Renumber as necessary, and repair all IDs and references in the
  same change. Git keeps the history.
- A `@decision ADR-NNNN` comment in code means stop and read that ADR first.
- [known-debt.md](known-debt.md) lists things that look deliberate but are not.
  You can improve those.
