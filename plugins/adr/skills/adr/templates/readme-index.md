# Architecture Decision Records

Read this index first. Open only the ADRs whose `paths` or topic match the code
you are about to touch. Never load every ADR.

Rules for agents:

- An `accepted` ADR is binding. Do not undo it. If it is wrong, run `/adr:new`
  to supersede it instead of editing it.
- A `@decision ADR-NNNN` comment in code means stop and read that ADR first.
- [known-debt.md](known-debt.md) lists things that look deliberate but are not.
  You may improve those.
