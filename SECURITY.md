# Seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades explotables, secretos ni datos privados en un issue. Usa **Security > Report a vulnerability** en GitHub para abrir un reporte privado:

https://github.com/BipBop-Labs/bipbop-skills/security/advisories/new

Incluye la skill o archivo afectado, impacto, pasos mínimos de reproducción y una mitigación sugerida si la conoces.

## Alcance

Tratamos como sensibles los cambios que agregan código ejecutable, hooks, conexiones MCP, dependencias, acceso de red, autenticación, permisos o instrucciones capaces de modificar sistemas externos. Las skills actuales son paquetes de instrucciones y recursos de texto.

Nunca incluyas tokens, credenciales, webhooks, datos de clientes, URLs internas ni identificadores privados en un reporte público o commit.
