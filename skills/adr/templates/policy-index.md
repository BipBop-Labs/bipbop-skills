# Policies

Rules and definitions that people and agents must obey. Read this index
first. Open only the policies whose `paths` or topic match your work.

Rules for agents:

- An `accepted` policy is binding. To change one, get confirmation and edit it
  in place. Git keeps the history.
- One rule, one doc. Link to a policy. Do not restate it in other docs or in
  agent instruction files.
- When a policy is past `last_reviewed` + `review_in`, its owner must review it.
